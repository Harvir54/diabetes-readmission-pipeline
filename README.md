# Diabetes Patient Readmission Analysis

## Problem
Which patients are most likely to be readmitted within 30 days, and what 
specific factors could a hospital intervene on to reduce readmissions and 
avoid Medicare penalties?

## Approach
- **Extract:** UCI Diabetes 130-US hospitals dataset (1999–2008), ~101,766 
  patient encounters
- **Transform:** SQL/Python cleaning (null handling, categorical 
  standardization, readmission flag cleanup)
- **Load:** Cleaned data loaded into MySQL
- **Analyze & Visualize:** SQL analysis + Tableau dashboard
